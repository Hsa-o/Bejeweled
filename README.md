# 💎 Bejeweled

Jogo inspirado no **Bejeweled**, desenvolvido em **C** utilizando a biblioteca **Raylib**.

## 🎮 Sobre o jogo

O objetivo é trocar gemas adjacentes para formar combinações de **3 ou mais gemas iguais**.

## 🛠️ Tecnologias

* **C**
* **Raylib**
* **GCC**

## ✨ Funcionalidades

* Tabuleiro 8x8
* 5 tipos de gemas
* Sistema de pontuação
* Combinação e remoção de gemas
* Queda e preenchimento do tabuleiro
* Sistema de desfazer jogada
* Música e efeitos sonoros
* Controle de volume
* Tela inicial e tela final
